# Customer Retention Strategies Analysis

## 📌 Project Overview

This project analyzes customer churn data using Python to identify:

- Key factors affecting customer churn
- Customer Lifetime Value (LTV)
- High-value customers at risk of churning
- Data-driven customer retention strategies

The project uses the **Telco Customer Churn Dataset** and generates visualizations along with CSV reports for business insights.

---


🎯 Objectives
Analyze customer churn patterns
Identify customers likely to leave
Calculate Customer Lifetime Value (LTV)
Detect high-value customers at risk
Suggest customer retention strategies
Generate business insights using visualizations

Python

Seaborn

📌 Key Business Insights
Month-to-month customers have higher churn rates
High monthly charges increase churn probability
Fiber optic users show higher churn
Long-term contracts reduce churn
High-value customers require personalized retention strategies

💡 Customer Retention Strategies
Encourage yearly contracts
Offer loyalty rewards
Improve customer support
Provide discounts for high-risk users
Send personalized offers to valuable customers
