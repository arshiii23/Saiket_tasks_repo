Telco Customer Churn Data Preprocessing

Internship Task 1 – Data Cleaning & Preprocessing

This project was completed as part of the internship task at SaiKet Systems.
The objective of this task was to clean and preprocess the Telco Customer Churn dataset by handling missing values and converting categorical data into numerical format.


---

Project Objective

The main goals of this project are:

Handle missing values in the dataset

Encode categorical variables into numerical format

Prepare the dataset for machine learning and analysis

Save the cleaned dataset for future use



---

Dataset

Dataset Used:

Telco_Customer_Churn_Dataset.csv

The dataset contains customer information related to telecom services and customer churn.


---

Technologies Used

Python

Pandas

NumPy

Scikit-learn

VS Code

---

Features Implemented

1. Missing Value Handling

Numerical missing values replaced using mean

Categorical missing values replaced using mode


2. Data Encoding

Converted categorical columns into numerical values using Label Encoding


3. Output Generation

Automatically creates output folder

Saves cleaned dataset as CSV file
